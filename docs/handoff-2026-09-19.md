## 1. Range map on the About page (approved, not started)

**Goal:** a 3D relief map of the Washington Cascades with a pin for every hike
page, in the "The Range" section of `src/pages/AboutPage.jsx`
(`<section className="about-regions-section">`), full width **above** the
existing two tag lists (keep the lists).

**Spec (as approved by Scott):**
- Tilted 3D relief, same look as the hike page map cards: forest-green recolored
  Esri shaded relief. Reuse `createReliefLayer(rect, level)` and the relief LUT
  from `src/lib/terrainFlyover.js` (export what you need), and
  `createTerrariumTerrainProvider()` from `src/lib/terrainFlyoverProvider.js`.
  The card already solves: one stitched relief image (no tile patchwork), full
  pixel density capped at 2x, `requestRenderMode` for a static map, and hiding
  the Cesium ion logo (`terrainFlyoverOverrides.css`). Keep the Esri
  "Data attribution" credit visible (required).
- About 420px tall on desktop, rounded like the site's cards (16px), full width
  of the section; roughly 300px on phones.
- One white dot per hike (white fill, `#1a1d1a` outline — same as the card's end
  dots). Hover shows the hike name; click navigates to `/hikes/<id>`
  (react-router `useNavigate`). The map itself doesn't need pan/zoom
  (`screenSpaceCameraController.enableInputs = false`, like the card), and page
  scrolling must still work over it (`touch-action: manipulation` is already set
  on Cesium canvases).
- Frame the Washington hikes (fit their bounding box with padding, tilted ~50°
  down, north up). The two Arizona hikes (Camelback Mountain, Subway Cave) go in
  a small "+ 2 in Arizona" note in a corner rather than as pins.
- Lazy-load Cesium the way `src/components/HikeMapCard.jsx` does
  (`window.CESIUM_BASE_URL = '/cesium/'` + dynamic import).

**Pin coordinates:** add a `trailhead: [lat, lon]` field to each hike in
`src/data/hikes.js`. For the 30 hikes with GPX, use the first track point
(`python3 scripts/flyover-check/gpxcheck.py <id>` prints it on the "starts"
line). For hikes without GPX (e.g. Camelback Mountain, Little Si — check which
lack a `hike_gpx` row), use the trailhead from the WTA page / a map. Garfield
Ledges and its winter page share one GPX.

**Lots of pins overlap** around I-90 (a dozen hikes within ~20km of Snoqualmie
Pass). Fine for a first version — hover still works — but mention it to Scott.

**Checking it cheaply:** one screenshot of the section at desktop width is
