**It must MATCH the 2D trail map on the individual hike cards** (Scott's
explicit requirement). That card is `src/components/HikeMapCard.jsx`, which
renders `TerrainFlyover` with `topDownPreview: true` (see
`src/lib/terrainFlyover.js`). Open any hike page on localhost and use its map
card as the visual reference. Same look, just a bigger area and many pins:
- **Straight-down 2D view, north up** — the card's top-down camera, NOT a
  tilted/3D view.
- **Same basemap:** the forest-green recolored Esri shaded relief, built the
  same way (`createReliefLayer(rect, level)` + the `RELIEF_STOPS` /
  `RELIEF_LUT` recolor in `terrainFlyover.js` — export and reuse them, don't
  re-create the colors). One stitched image (no tile patchwork), full pixel
  density capped at 2x, `requestRenderMode` (static map), same terrain provider
  (`createTerrariumTerrainProvider()`), Cesium ion logo hidden via
  `terrainFlyoverOverrides.css`.
- **Same pins as the card's trail-end dots:** white fill, `#1a1d1a` outline
  (`TRAIL_CASING`), 11px, drawn on top (the card's PointPrimitiveCollection
  settings).
- **Same card shape and chrome:** same rounded corners (16px) and the same
  frosted caption band style as the hike card (`.map-card-body` /
  `.map-card-title` in `src/index.css`), with the Esri "Data attribution" link
  placed inside the band on the right exactly as the card does
  (`.map-card .cesium-viewer-bottom` rule — required by Esri's terms). Ask
  Scott what the band's title should say; don't invent copy.
- About 420px tall on desktop, full width of the section; ~300px on phones.
- Interaction: hover a pin to show the hike's name; click to open
  `/hikes/<id>` (react-router `useNavigate`). No pan/zoom
  (`screenSpaceCameraController.enableInputs = false`, like the card); page
  scrolling must still work over it (`touch-action: manipulation` is already set
  on Cesium canvases).
- Fit the Washington hikes' bounding box (with padding). The two Arizona hikes
  (Camelback Mountain, Subway Cave) go in a small "+ 2 in Arizona" note rather
  than as pins.
- Lazy-load Cesium the way `HikeMapCard.jsx` does
  (`window.CESIUM_BASE_URL = '/cesium/'` + dynamic import).
- **Don't add anything beyond this spec** (legends, extra labels, animation,
  controls) — Scott has pushed back hard on invented UI. Ask first.

**Pin coordinates:** add a `trailhead: [lat, lon]` field to each hike in
